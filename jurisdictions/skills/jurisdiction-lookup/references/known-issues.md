# Known Issues in the Jurisdiction References

Found during integration (checked 2026-11-26). This file **overrides** the reference files. The reference files were copied unchanged. Only the points below were checked: everything else is as declared by the content author.

## United States

### `aml.md`: FinCEN Residential Real Estate Rule is vacated

The file presents 31 CFR 1031.320 as in force. A federal court in the Eastern District of Texas vacated it on 2026-03-19, and FinCEN states that reporting persons are not required to file while that order stands. FinCEN has appealed, so the duty could return. Check the current status before every use. Do not tell a user that a report is required, or that the duty is gone for good. Statements in the same file that depend on the rule (including that it replaced the Geographic Targeting Orders, and its first test case) are affected.

- https://www.fincen.gov/rre-faqs
- https://www.gibsondunn.com/fincen-residential-real-estate-reporting-rule-vacated-nationwide/

### `privacy.md`: TCPA one-to-one consent

The file lists one-to-one seller consent as part of prior express written consent. The Eleventh Circuit vacated that FCC rule on 2025-01-24. Other prior express written consent requirements remain.

- https://www.mofo.com/resources/insights/250130-eleventh-circuit-vacates-fcc-s-tcpa-one-to-one-consent-rule

### `leasing.md`: HUD assistance animal guidance was withdrawn

The file relies on HUD notice FHEO-2020-01, including for emotional support animals without pet fees. Law firm reports say HUD withdrew it (September 2025) and permanently cancelled it (May 2026). The Fair Housing Act was not amended and state or local rules may still apply. Escalate every assistance animal request to a lawyer.

- https://www.hklaw.com/en/insights/publications/2026/06/hud-rescinds-emotional-support-animal-guidance

## United States and Europe

The `## Process` section is **empty** in all eight files of each folder. Do not invent a process: use the rules in the file and the department skill, and say the process is not documented.

## Brazil

### `aml.md`: confirm the COFECI resolution in force

The file relies on COFECI Resolution 1.336/2014 "and updates". No repeal was found, but the current consolidated text could not be confirmed. A 2022 resolution (1.463/2022) is reported to amend it. Check with COFECI before relying on deadlines or thresholds.

- https://intranet.cofeci.gov.br/arquivos/legislacao/resolucao_1336_2014.pdf

### `aml.md`: threshold conflicts with the company context example

The file states R$ 100,000 for automatic reporting of cash operations. The company context example delivered later states R$ 50,000. Neither was verified. A company may set a stricter internal rule, but confirm the legal threshold with counsel before using either.

## All files

Every jurisdiction file declares `confidence: verified`. Treat that as the author's declaration, not as independent verification.
