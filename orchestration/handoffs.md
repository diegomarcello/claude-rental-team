# Handoffs

Derived from the order of the skills in the six workflows. Triggers, deliverables and deadlines are not defined yet.

| From | To | Skill sequence |
|---|---|---|
| `marketing` | `legal` | campaign-planning → contract-drafting-review (listing-to-sale) |
| `legal` | `appraisal` | contract-drafting-review → comparative-market-analysis (listing-to-sale) |
| `appraisal` | `marketing` | comparative-market-analysis → listing-copywriting (listing-to-sale) |
| `marketing` | `pre-sales` | listing-copywriting → lead-qualification (listing-to-sale); listing-copywriting → lead-qualification (lease-lifecycle) |
| `pre-sales` | `sales` | visit-scheduling → proposal-negotiation (listing-to-sale) |
| `sales` | `legal` | proposal-negotiation → title-due-diligence (listing-to-sale) |
| `legal` | `sales` | privacy-aml → closing-checklist (listing-to-sale) |
| `sales` | `finance` | closing-checklist → accounts-receivable (listing-to-sale) |
| `finance` | `sales` | accounts-receivable → commission-calculation (listing-to-sale) |
| `sales` | `post-sales` | commission-calculation → property-handover (listing-to-sale) |
| `acquisitions` | `appraisal` | opportunity-screening → technical-inspection (buy-renovate-resell) |
| `appraisal` | `legal` | comparative-market-analysis → title-due-diligence (buy-renovate-resell) |
| `legal` | `acquisitions` | title-due-diligence → deal-feasibility (buy-renovate-resell) |

| `procurement` | `finance` | vendor-management → accounts-payable (maintenance-and-warranty) |
| `finance` | `executive` | financial-close → company-kpis (governance-and-close) |
| `executive` | `finance` | company-kpis → cash-flow-forecast (governance-and-close) |
| `finance` | `technology-data` | cash-flow-forecast → bi-reporting (governance-and-close) |
